Microplastic Contamination Index

Scientific basis, computation, and interpretation used for assessing suspected microplastic contamination.

Scientific Basis

MicroCount uses particle abundance as an indicator of suspected microplastic contamination. Because MicroCount analyzes microscope images rather than measuring polymer concentration directly, the result should be interpreted as an indicator of observed particle contamination rather than a measurement of human health risk.

Published microplastic studies have adapted contamination-factor and pollution-load approaches to compare measured microplastic abundance with a reference or baseline concentration.

Contamination Factor

The contamination factor compares the measured microplastic concentration with a selected baseline or reference concentration.

CF = Ci / C0
CF = Contamination Factor
Ci = measured microplastic concentration
C0 = reference or baseline microplastic concentration
Important: A valid contamination factor requires a scientifically justified reference or baseline. MicroCount should not invent a baseline value.

Pollution Load Index

Published studies have also used the Pollution Load Index (PLI) to summarize microplastic pollution relative to reference concentrations.

PLI = √CF

When multiple sampling sites or categories are available, published applications may calculate an overall PLI using the geometric mean of the individual pollution-load indices.

PLIoverall = ⁿ√(PLI1 × PLI2 × ... × PLIn)

Step-by-Step Computation

  1. Determine the measured particle concentration.
    MicroCount obtains the number of suspected particles detected in the analyzed microscope images.

  2. Determine the reference concentration.
    A scientifically justified background or baseline value must be selected from an appropriate published source or reference dataset.

  3. Calculate the Contamination Factor.
    Divide the measured concentration by the reference concentration.

  4. Calculate the Pollution Load Index, when appropriate.
    The contamination factor can be transformed according to the published PLI framework.

  5. Interpret the result.
    Higher values indicate a greater measured microplastic load relative to the selected baseline.

Application to MicroCount

MicroCount currently reports suspected particles per microscope image. Therefore, the MicroCount average particle count can be used as an observational abundance measure.

Example:

Suppose MicroCount detects an average of 12.5 suspected particles/image across the analyzed microscope images.

This value describes the observed particle abundance in the analyzed images. It should not automatically be converted into a contamination factor unless an appropriate reference value measured using a comparable method and unit is available.

Interpretation

Result Interpretation
CF < 1 Measured concentration is below the selected reference value.
CF = 1 Measured concentration equals the selected reference value.
CF > 1 Measured concentration is higher than the selected reference value.

These interpretations describe contamination relative to the chosen baseline. They should not be interpreted as direct human-health risk levels.

Important Scientific Limitation

MicroCount detects suspected particles visible in microscope images. Microscopic particle counts do not by themselves establish polymer identity, chemical composition, particle mass, human absorbed dose, or disease risk.

Therefore, the Contamination Index should be used for environmental comparison and research interpretation rather than as a clinical health-risk assessment.
